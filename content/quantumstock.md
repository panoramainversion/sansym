# 股票交易的量子效应

quantum effect of stock trading  
市场微观运行遵循量子系统规律

| **金融** | **物理** |
| :------: | :------: |
| 本金 | 初始能量 |
| 盈亏 | 能量变化 |
| 涨跌 | 速度 |

| 买入 | 正向力 |
| 卖出 | 反向力 |

经典力学框架仅适用于宏观描述，微观交易层面确定性失效。

## 叠加态坍缩
成交前价格处于涨跌叠加态：  
$|\psi\rangle = \alpha |涨\rangle + \beta |跌\rangle$  
$|\alpha|^2 + |\beta|^2 = 1$

成交即测量，叠加态坍缩为确定成交价。  
报价是概率分布，成交才是真实值。

## 不确定性原理
$\Delta x \cdot \Delta p \geqslant \frac{\hbar}{2}$  

位置与动量不可同时测准。  
市场对应：价格与趋势不可兼得。  
精确点位牺牲趋势确定性，明确趋势放弃点位精度。

## 量子纠缠
纠缠粒子呈非局域关联，测量其一瞬时同步全体。  
市场中个股、板块、大盘处于整体纠缠态。  
龙头价变，板块同步响应；  
系统风险来临时，全市场波函数同步坍缩。

## 隧道效应
经典：能量不足无法跨越势垒。  
量子：粒子以概率穿透势垒。  
  
市场阻力位常现「价先破，量后至」。  
价格以概率波穿透势能高点，资金随后确认。

## CPT联合守恒
物理定律在 $C$,$P$,$T$ 联合变换下不变。  
市场满足同一守恒律：  

- 电荷共轭 $C$ ↔ 多空共轭  
- 宇称反转 $P$ ↔ 涨跌反射  
- 时间反演 $T$ ↔ 周期对偶  

单一对称均可破缺，三者联合则严格守恒。
